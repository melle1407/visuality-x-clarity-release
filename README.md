## 🚀 Getting Started

### Installation

1. Go to the [Releases Page](https://github.com/melle1407/visuality-x-clarity-release/releases/latest).
2. Download `Visuality-Clarity-1.0.0-x64.zip`[cite: 1].
3. Extract the contents and run the setup application.

### Screenshots Setup
To ensure your screenshots load correctly in this README:
1. Create a folder named `docs/screenshots` in your root repository directory.
2. Place your login screen image inside and name it `login.png`.
3. Add any main editor screenshots as `dashboard.png`.
